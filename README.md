# ALYA PERFUMES

Loja online de perfumes árabes de luxo — fragrâncias exclusivas com alta fixação e projeção premium.

## Tecnologias

- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS

## Desenvolvimento local

Requisito: Node.js & npm instalados.

```sh
# 1. Clonar o repositório
git clone <YOUR_GIT_URL>

# 2. Entrar na pasta do projeto
cd perfumes

# 3. Instalar as dependências
npm install

# 4. Iniciar o servidor de desenvolvimento
npm run dev
```

## Build de produção

```sh
npm run build
```

Os arquivos estáticos são gerados em `dist/`.

## Deploy

O projeto está hospedado na Vercel: https://alyaperfumes.vercel.app/
